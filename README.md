It is a.lang file that allows highlighting visual foxpro code in gedit . It was vibe coded using claude. to install it:

1. close gedit

2. copy file to usr/share/libgedit-gtksourceview-<version>/language-specs
e.g.
cp ~/Downloads/visualfoxpro.lang to usr/share/libgedit-gtksourceview-300/language-specs

3. open a .prg file in gedit
